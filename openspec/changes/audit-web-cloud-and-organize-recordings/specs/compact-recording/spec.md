## ADDED Requirements

### Requirement: Ogg означает настоящий контейнер
Desktop SHALL поддерживать создание воспроизводимого Ogg/Opus архива. Web SHALL предлагать Ogg/Opus только при реальной поддержке кодировщика; MIME, расширение и содержимое MUST соответствовать друг другу.

#### Scenario: Браузер без Ogg
- **WHEN** Ogg/Opus недоступен, но WebM/Opus поддерживается
- **THEN** выбирается честно обозначенный WebM/Opus fallback, а не переименованный файл .ogg.

### Requirement: Компактный профиль по умолчанию
Для новых настроек приложение SHALL выбирать наиболее компактный из проверенных поддерживаемых профилей пригодного для речи качества. Выбор SHALL основываться на измерениях одинакового материала; сохранённый явный выбор пользователя имеет приоритет.

#### Scenario: Первый запуск
- **WHEN** пользователь начинает запись без сохранённых предпочтений
- **THEN** выбран измеренный компактный профиль; доступные lossless-форматы остаются явным выбором.

### Requirement: Независимость архива и распознавания
Кодирование MUST не блокировать захват или зависеть от сети; исходные устойчиво сохранённые данные SHALL оставаться доступными при ошибке финализации. Существующие архивы MUST не перекодироваться автоматически.

#### Scenario: Ошибка кодировщика
- **WHEN** финализация Ogg завершается ошибкой
- **THEN** пользователь получает явную ошибку и возможность восстановления без silent data loss.
