# Spec Delta

## Purpose
Обеспечить воспроизводимую и честную оценку выполнения дорожной карты и пользовательских сценариев приложения.

## ADDED Requirements

### Requirement: Доказуемая готовность
Отчёт SHALL связывать каждое утверждение дорожной карты с кодом, командой проверки, результатом и проверенной ревизией; различать verified, not-run, blocked_external и failed.

#### Scenario: Противоречащие отчёты
- **WHEN** STATUS объявляет завершение при pending-этапах
- **THEN** аудит фиксирует противоречие и не объявляет план полностью проверенным до сверки evidence и повторных проверок.

### Requirement: Основной веб-интерфейс
Web SHALL позволять записать доступный источник, сохранить звук локально, открыть запись после перезагрузки, воспроизвести и экспортировать её без вызова Desktop IPC. Недоступное системное аудио SHALL иметь явный fallback.

#### Scenario: Работа без сети
- **WHEN** пользователь записывает через основной интерфейс при отключённой сети и затем перезагружает страницу
- **THEN** сохранённая запись доступна из OPFS и метаданных IndexedDB без потери звука; сетевое распознавание отображается отдельным состоянием.

### Requirement: Честные границы проверки
Система отчётности MUST отличать synthetic/harness/mock проверки от реальных устройств, основного UI, VPS и OAuth.

#### Scenario: Нет доступа к аккаунту
- **WHEN** mock OAuth проходит, но реальное согласие пользователя недоступно
- **THEN** реальный OAuth остаётся blocked_external, а результат mock указан отдельно.
