## ADDED Requirements

### Requirement: Реальные облачные подключения
UI SHALL предоставлять отдельные подключения Google Drive и Яндекс.Диск с состояниями отключено, авторизация, подключено, истекло, отозвано и ошибка. Производственное подключение MUST использовать реальный провайдер, а не mock.

#### Scenario: Нет OAuth-конфигурации
- **WHEN** приложение не настроено для выбранного провайдера
- **THEN** UI объясняет недостающую настройку и не показывает фиктивное успешное подключение.

#### Scenario: Ошибочный callback
- **WHEN** callback не соответствует начатой авторизации либо повторно использует ответ
- **THEN** подключение отклоняется без сохранения токена и без вывода секретов в сообщения.

### Requirement: Долговечная синхронизация
Синхронизация SHALL сохранять записи, аудио, изменения текста, папки и порядок как отдельные данные, поддерживать повтор после сбоя без дублирования и не выгружать общий SQLite-файл. Конфликтующие изменения MUST сохранять пользовательские данные, а не молча терять одну версию.

#### Scenario: Сбой передачи
- **WHEN** сеть пропадает во время передачи аудио
- **THEN** локальная запись остаётся доступной, повторная передача идемпотентна, а synced_to_cloud устанавливается только после проверки удалённой целостности.

#### Scenario: Отзыв доступа
- **WHEN** пользователь отключает облако либо провайдер отзывает доступ
- **THEN** синхронизация останавливается, секреты удаляются согласно политике хранения, локальные данные сохраняются.
