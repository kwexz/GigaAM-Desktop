Your recordings.
Your words. Your control.

GigaAM Desktop records audio, transcribes Russian speech and organizes transcripts. Desktop uses a local model; Web can use a separately deployed recognition server.

Project and source codeSupport and feedback
An independent, unofficial project. Not an official product of the GigaAM developers, Google or Yandex. This website provides product information; it is not an audio upload service.

Local by default

Desktop keeps audio and transcripts on your device. Web saves original recordings in private browser storage. Server recognition involves sending audio to the configured server.

Cloud only by choice

Google Drive and Yandex Disk connections are under development. The planned integration will save user recordings and related data with explicit permission. Public OAuth connections are not currently offered.

Transparency, not extra promises

Features and limitations depend on the version, operating system and browser. Current code, licensing and issue reports are available in the repository. Before processing confidential conversations, check your selected storage and recognition mode.
