Privacy policy · October 30, 2026

Privacy

This policy covers the informational website gad.ismvp.host and the available modes of GigaAM Desktop. The operator is the maintainers of kwexz/GigaAM-Desktop. Contact: GitHub Issues. Do not post private audio, transcripts or tokens there.

This website

The site has no upload forms, advertising trackers, third-party fonts or analytics, and does not use cookies for profiling. The web server may record technical logs including IP address, time, URL, HTTP status and browser information. These are used to operate and diagnose the site, not for advertising. Never include secrets in URLs.

The application and audio

  • Desktop stores recordings and transcripts locally. Local recognition does not require sending audio to this website's operator.
  • Web stores audio in OPFS and metadata and text in IndexedDB for the current origin and browser profile.
  • Server recognition sends audio to the configured server. The administrator of your self-hosted installation is responsible for access, logging, retention and deletion on that server. This page does not establish a universal policy for third-party VPS installations.
  • When following GitHub links, that service's policies apply.

Google Drive and Yandex Disk

These integrations are under development. Public sign-in and OAuth data processing are not currently offered on this website. This section describes the intended future access, not an already available feature.

Planned data includes selected audio files, transcripts, recording names, folders and synchronization metadata. The purpose is to upload, restore and synchronize those data, not to access unrelated files. Google integration is intended to use the minimal drive.file scope; actual permissions must be displayed on the consent screen.

Google data is not intended for sale, advertising, creditworthiness assessment or training generalized AI/ML models. Use and transfer of information received from Google APIs must comply with the Google API Services User Data Policy, including Limited Use requirements. This policy must be checked against the actual implementation before public release.

Access tokens are used only for authorized operations. Never disclose Google or Yandex passwords to the application, issue tracker or site operator. Token protection details and an updated policy will be published with the completed integration; this page does not claim a completed secure OAuth credential store.

Your control and deletion

See data deletion and access revocation. Revoking OAuth access does not itself delete previously uploaded files. Clearing browser storage may permanently delete local archives: export important recordings first.

Updates

The revision date appears above. This policy will be updated before public cloud processing changes are enabled. Contact project support for privacy questions without posting sensitive information.
