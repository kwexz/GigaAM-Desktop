Data control

Delete your data

Local recordings

Delete recordings through the application's history. To remove all Desktop data, first close the application and export anything you need, then remove its application data directory. Uninstalling the program alone may leave history and audio behind.

In Web, use recording deletion in the interface. Clearing site data in your browser removes IndexedDB and OPFS for that origin, potentially permanently deleting audio, text and folders. Other domains and profiles must be cleared separately.

Recognition server

If you used a self-hosted server, contact its administrator to delete server copies, jobs, spool files and backups. Clearing your browser does not delete VPS data. This informational website does not provide accounts or accept audio uploads.

Google

  1. Open your Google Account's third-party connections.
  2. Find GigaAM Desktop and remove its access if you previously granted it.
  3. Delete unwanted application files or folders in Google Drive, and empty the trash if needed.

Yandex

Open permissions or connected applications in Yandex ID and revoke GigaAM Desktop access if previously granted. Delete Disk files separately, including the trash.

Cloud connections are under development. Revoking permission stops future access but does not automatically delete previously saved files. Local and cloud copies are independent.

Requests to the operator

Project contact: GitHub Issues. Describe your question without posting private audio, tokens or documents. Arrange a private channel with the maintainer before sending sensitive information.
