GigaAM Desktop — приложение для записи аудио, распознавания русской речи и организации транскриптов. Desktop работает с локальной моделью; Web может использовать отдельно развёрнутый сервер распознавания.

Проект и исходный кодПоддержка и обратная связь
Независимый неофициальный проект. Не является официальным продуктом разработчиков GigaAM, Google или Яндекса. Этот сайт — информация о приложении, а не сервис загрузки аудио.

Локально по умолчанию

В Desktop аудио и транскрипты хранятся на устройстве. В Web исходные записи сохраняются в приватном хранилище браузера. Серверное распознавание предполагает передачу аудио на выбранный сервер.

Облако — только по выбору

Подключение Google Drive и Яндекс.Диска находится в разработке. Планируемая интеграция предназначена для сохранения пользовательских записей и связанных данных по явному разрешению. Сейчас публичное OAuth-подключение не предлагается.

Прозрачность вместо лишних обещаний

Возможности и ограничения зависят от версии, операционной системы и браузера. Актуальный код, лицензия и сообщения об ошибках доступны в репозитории. До использования с конфиденциальными разговорами проверьте выбранный режим хранения и распознавания.
