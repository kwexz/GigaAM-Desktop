Удаление данных

Локальные записи

Удаляйте записи через историю приложения. Для полного удаления Desktop-данных сначала закройте приложение и сохраните необходимые экспорты, затем удалите каталог данных приложения. Удаление только программы может оставить историю и аудио.

В Web используйте удаление записей в интерфейсе. Полная очистка данных сайта в настройках браузера удаляет IndexedDB и OPFS данного origin: это может безвозвратно удалить звук, текст и папки. Данные другого домена или профиля очищаются отдельно.

Сервер распознавания

Если использовался self-hosted сервер, обратитесь к его администратору для удаления серверных копий, заданий, spool и резервных копий. Очистка браузера не удаляет данные на VPS. Текущий информационный сайт не предоставляет аккаунты и не принимает аудио.

Google

  1. Откройте связи Google-аккаунта со сторонними приложениями.
  2. Найдите GigaAM Desktop и удалите его доступ, если он ранее выдавался.
  3. Удалите ненужные файлы/папку приложения в Google Drive и очистите корзину при необходимости.

Яндекс

В настройках Яндекс ID откройте раздел разрешений или приложений с доступом и отзовите доступ GigaAM Desktop, если он выдавался. Файлы на Диске удаляйте отдельно, включая корзину.

Облачные подключения находятся в разработке. Отзыв разрешения останавливает будущий доступ, но не удаляет автоматически ранее сохранённые данные. Локальные и облачные копии независимы.

Запросы оператору

Контакт проекта: GitHub Issues. Для обращения достаточно описания вопроса; не публикуйте приватные аудиофайлы, токены или документы. Инструкция закрытого канала для чувствительных запросов должна быть согласована с сопровождающим до передачи таких данных.
