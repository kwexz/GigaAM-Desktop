Конфиденциальность

Эта политика описывает информационный сайт gad.ismvp.host и доступные режимы GigaAM Desktop. Оператор — сопровождающие открытого репозитория kwexz/GigaAM-Desktop; контакт — GitHub Issues. Не публикуйте там приватное аудио, транскрипты и токены.

Сайт

Сайт не содержит форм загрузки, рекламных трекеров, сторонних шрифтов и аналитики; не использует cookies для профилирования. Веб-сервер может записывать технические журналы: IP-адрес, время, URL, HTTP-статус и сведения браузера. Они используются для работы и диагностики сайта, не для рекламы. Не передавайте секреты в адресной строке.

Приложение и аудио

  • Desktop сохраняет записи и транскрипты локально. Локальное распознавание не требует передачи аудио оператору этого сайта.
  • Web сохраняет аудио в OPFS, метаданные и текст — в IndexedDB текущего origin и профиля браузера.
  • При серверном распознавании аудио передаётся настроенному серверу. Администратор вашей self-hosted установки отвечает за доступ, журналы, сроки хранения и удаление на этом сервере. Эта страница не утверждает единую политику для чужих VPS.
  • При переходе на GitHub действуют правила соответствующего сервиса.

Назначение — загрузка, восстановление и синхронизация этих данных, а не доступ ко всем посторонним файлам. Токены доступа используются только для разрешённых операций. Не передавайте пароли Google/Яндекс приложению, в issue или оператору сайта. Контроль и удаление

Инструкция: удаление локальных и облачных данных, отзыв доступа. Отзыв OAuth-доступа сам по себе не удаляет ранее загруженные файлы. Очистка данных браузера может безвозвратно удалить локальные архивы — сначала экспортируйте нужные записи.

Изменения

Дата редакции указана вверху. При изменении облачной обработки политика будет обновлена до её публичного включения. По вопросам конфиденциальности обращайтесь через страницу поддержки проекта, без публикации чувствительных данных.
