# Эксперимент с окнами диаризации — обезличенная запись

Дата: 2026-11-12. Исходная запись и база не изменялись; использовалась копия базы и локальная модель WeSpeaker ResNet34. Выбор пользователя: четыре говорящих. Два контрольных интервала преимущественно одного участника: 65:35–65:53 и 66:53–67:15, возможно присутствует другой голос.

## Метод

В release-сборке сравнивались окна внутри существующих сегментов расшифровки, кластеризация — текущая, четыре группы. Учитывались окна, целиком помещающиеся в контрольные интервалы; остатки от 0,5 с учитываются. Время включает последовательное чтение, декодирование, вычисление эмбеддингов и кластеризацию, но не загрузку модели и компиляцию. Разные номера групп между прогонами не означают одинаковые личности.

Отдельный эксперимент только на аудио 65:00–67:15 с независимой кластеризацией дал другие результаты: для 1,5 и 2 с оба интервала преимущественно совпали; для 3, 5 и 3 с с перекрытием — нет. Это демонстрирует зависимость группировки от контекста всей записи; эти данные нельзя напрямую сравнивать с полной записью.

## Вывод и ограничения

- Все пять конфигураций в полном прогоне дали одну преобладающую группу для двух контрольных интервалов. У пятисекундных окон меньше наблюдений, поэтому результат 5/5 не доказывает превосходства.
- Перекрытие 50% увеличило время примерно на 83% и на первом контрольном интервале дало менее устойчивую группу. На этих данных его включать не обосновано.
- Оставлено 3 с без перекрытия: существенного преимущества замены по двум частично размеченным интервалам не доказано. Это не доказательство оптимальности.
- Не измерены точность оставшихся трёх голосов, ошибки смешанной речи, пропуски речи и DER/JER. Группы 3 и 4 из старого запуска пользователь назвал одним человеком, но временная разметка для проверки этого утверждения отсутствует. Четвёртый голос не может быть достоверно оценён только по двум частично смешанным интервалам.
- Конфигурация приложения не менялась. Эксперимент не проверял GUI и не перезаписывал пользовательские метки.

Для воспроизведения: `cargo test --release --locked --manifest-path src-tauri/Cargo.toml --lib experiment_full_recording -- --ignored --nocapture`; переменные окружения `GIGAAM_SPEAKER_MODEL`, `GIGAAM_DIARIZATION_AUDIO`, `GIGAAM_DIARIZATION_DB`, `GIGAAM_DIARIZATION_ID`, `GIGAAM_EXPERIMENT_SECONDS`, `GIGAAM_EXPERIMENT_OVERLAP` задаются локально. База для теста должна быть копией; аудио, пути к нему и эмбеддинги не включать в репозиторий.
