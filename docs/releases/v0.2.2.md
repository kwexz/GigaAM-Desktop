# GigaAM Desktop v0.2.2

## Русский

Обновление улучшает запись, работу с расшифровками и саммари. Распознавание по-прежнему работает локально после явной загрузки необходимых моделей.

### Новое и исправления

- Записи и папки можно упорядочивать перетаскиванием; новые записи появляются сверху. Добавлен импорт файлов с расширением `.opus` и других поддерживаемых форматов.
- Восстановлен индикатор распознавания, добавлена остановка распознавания и генерации саммари. Усиление микрофона можно менять во время записи; начальное значение — 1×.
- Для саммари доступны изменяемый промпт, визуальное редактирование и режим Markdown. Локальные варианты работают через выбранный Ollama или GGUF; совместимый API получает текст расшифровки только при явном выборе.
- Экспериментальная диаризация позволяет выбрать количество говорящих или автоматический режим. Теперь анализируются окна по всей длине фрагмента, а не только его начало. Метки можно исправлять вручную.
- Исправлены продолжение воспроизведения после паузы и выравнивание элементов интерфейса.

### Ограничения

- Диаризация может ошибаться, особенно при перекрывающейся речи и коротких репликах. Одному сегменту назначается преобладающий голос; качество для конкретной записи не гарантируется. Модель говорящих загружается отдельно по действию пользователя.
- Отмена API-запроса не гарантирует остановку вычислений на удалённом сервере. При использовании GGUF или Ollama требуется отдельно настроенный локальный runtime и модель.
- Windows-сборки не подписаны; SmartScreen может показать предупреждение. Подписанный и нотаризованный пакет macOS доступен только после успешного завершения соответствующей сборки и появления его в файлах релиза.

## English

This update improves recording, transcript workflows and summaries. Recognition remains local after the required models are explicitly downloaded.

### Changes

- Organize recordings and folders by dragging; new recordings appear first. Import now accepts `.opus` and other supported formats.
- Recognition progress is visible again, and recognition and summary generation can be stopped. Microphone gain is adjustable during recording and defaults to 1×.
- Summaries now support an editable prompt, visual editing and Markdown mode. Local backends use a selected Ollama or GGUF runtime; an explicitly selected compatible API receives the transcript.
- Experimental diarization offers automatic or user-selected speaker counts. Windows across the whole transcript segment are analyzed rather than only its beginning. Speaker labels can be edited.
- Fixed playback resumption after pausing and refined interface alignment.

### Limitations

- Diarization can misidentify speakers, especially during overlapping speech or short turns. A segment receives its dominant speaker; accuracy for any particular recording is not guaranteed. The speaker model requires a separate explicit download.
- Cancelling an API request does not guarantee that the remote provider stops processing. GGUF and Ollama require a separately configured local runtime and model.
- Windows builds are unsigned and may trigger SmartScreen. A signed, notarized macOS package is available only after its build succeeds and the asset appears on the release page.
