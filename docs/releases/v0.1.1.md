# GigaAM Desktop v0.1.1

## English

Release focused on reproducible packaging and macOS distribution.

### Changes since v0.1.0

- Added tag-driven GitHub Release automation with separate Windows and macOS jobs.
- Added Windows NSIS and portable artifacts to every tagged release.
- Added signed and notarized Apple Silicon macOS DMG/app artifacts.
- Added release timeouts and sleep prevention for the former macOS build runner.
- Kept pull-request checks on trusted GitHub-hosted infrastructure.

### Downloads

- **Windows x64:** `GigaAM.Desktop_0.1.1_x64-setup.exe` or portable `gigaam-desktop.exe`.
- **macOS arm64:** signed/notarized `GigaAM.Desktop_0.1.1_aarch64.dmg`; `GigaAM.Desktop_aarch64.app.tar.gz` is also attached.

### Important notes

- Windows artifacts are unsigned and may trigger SmartScreen.
- Models (~227 MB) are downloaded once and verified by size and SHA-256; transcription works offline afterwards.
- The repository MIT license does not relicense downloaded models or third-party dependencies.

## Русский

Релиз посвящён воспроизводимой упаковке и публикации macOS-сборок.

### Изменения относительно v0.1.0

- Добавлена автоматическая публикация GitHub Release по тегам с отдельными Windows- и macOS-задачами.
- В каждый тегированный релиз добавляются Windows NSIS и portable-файл.
- Добавлены подписанные и нотаризованные DMG/app для Apple Silicon macOS.
- Добавлены таймауты релиза и защита прежнего macOS build runner от сна.
- Проверки pull request оставлены на доверенной GitHub-hosted инфраструктуре.

### Загрузки

- **Windows x64:** установщик `GigaAM.Desktop_0.1.1_x64-setup.exe` или portable `gigaam-desktop.exe`.
- **macOS arm64:** подписанный и нотаризованный `GigaAM.Desktop_0.1.1_aarch64.dmg`; также приложен `GigaAM.Desktop_aarch64.app.tar.gz`.

### Важно

- Windows-файлы не подписаны и могут вызвать предупреждение SmartScreen.
- Модели (~227 МБ) загружаются один раз с проверкой размера и SHA-256; после этого транскрибация работает без интернета.
- MIT-лицензия репозитория не перелицензирует загружаемые модели и сторонние зависимости.
