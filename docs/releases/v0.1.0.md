# GigaAM Desktop v0.1.0

## English

First public release of the local Russian speech-transcription desktop application.

### Highlights

- Import audio and video files for local transcription.
- Record microphone audio, system audio, or both sources as separate tracks.
- On-device GigaAM v3 E2E CTC inference with Silero VAD through ONNX Runtime.
- Persistent SQLite queue and history.
- Timestamped transcript playback, search, retry, and TXT/SRT/WebVTT/JSON export.
- One-time verified model download (~227 MB); recognition works offline afterwards.

### Downloads

- **Windows x64:** `GigaAM.Desktop_0.1.0_x64-setup.exe` or portable `gigaam-desktop.exe`.
- **macOS arm64:** `GigaAM-Desktop-0.1.0-aarch64.zip`.

### Important notes

- Windows and macOS artifacts in this release are unsigned. Windows SmartScreen or macOS quarantine may warn.
- macOS: unpack the archive and use **Control-click → Open** if Gatekeeper blocks the first launch.
- Models are not bundled and are downloaded on first use.
- The repository MIT license does not relicense downloaded models or third-party dependencies.

## Русский

Первый публичный релиз десктопного приложения для локального распознавания русской речи.

### Главное

- Импорт аудио- и видеофайлов для локальной транскрибации.
- Запись микрофона, системного звука или обоих источников отдельными дорожками.
- Локальный инференс GigaAM v3 E2E CTC с Silero VAD через ONNX Runtime.
- Персистентная очередь и история в SQLite.
- Воспроизведение по таймкодам, поиск, повтор распознавания и экспорт TXT/SRT/WebVTT/JSON.
- Однократная проверяемая загрузка моделей (~227 МБ), после которой распознавание работает без интернета.

### Загрузки

- **Windows x64:** установщик `GigaAM.Desktop_0.1.0_x64-setup.exe` или portable `gigaam-desktop.exe`.
- **macOS arm64:** `GigaAM-Desktop-0.1.0-aarch64.zip`.

### Важно

- Windows- и macOS-файлы этого релиза не подписаны. Возможны предупреждения Windows SmartScreen или macOS quarantine.
- На macOS распакуйте архив и при блокировке первого запуска используйте **Control-click → Open**.
- Модели не входят в пакет и загружаются при первом использовании.
- MIT-лицензия репозитория не перелицензирует загружаемые модели и сторонние зависимости.
