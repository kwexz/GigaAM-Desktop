## Evidence

- Автоматический prompt получен в той же интерактивной сессии после завершения предыдущего ответа.
- Статус инструмента: runs=1, lastEvent=session.execution.succeeded, lastEventAt=2026-10-28T20:19:57.537Z.
- Код приложения в рамках smoke-проверки не изменялся.
- Подтверждён один реальный цикл continuation; другие сценарии (перезапуск сервера, длительный цикл) этой проверкой не подтверждаются.

## Инцидент: лишний prompt после закрытого checklist

- После закрытия smoke-checklist пришёл второй автоматический prompt. Причина не установлена: журнала событий плагина не хватало.
- Исправление (плагин `~/.config/opencode/plugins/task-continuity`, вне репозитория):
  - дедупликация по идентификатору события (`event.id`, иначе `durable.aggregateID:seq`) в памяти и в plugin storage (`lastEventID`);
  - продолжение не отправляется при полностью закрытом checklist;
  - в тексте продолжения агенту запрещено начинать новую работу, если все пункты уже отмечены;
  - в состоянии хранится история последних 5 событий для будущей диагностики.
- Regression tests: `npm test` в каталоге плагина — 9/9 pass, включая повторную доставку события, replay после перезапуска и остановку на закрытом checklist.
- **not-run:** живой прогон после исправления. Плагин загружается при старте OpenCode, поэтому исправление применяется только после перезапуска приложения.
